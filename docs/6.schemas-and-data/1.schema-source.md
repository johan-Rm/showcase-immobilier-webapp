# Schema Source

- Role: documenter la source de verite des schemas et les invariants transverses des contrats de donnees.
- Related: [./2.interface-generation.md](./2.interface-generation.md), [../../schemas/README.md](../../schemas/README.md)

## Overview

Dans ce projet, les schemas ne sont pas seulement une arborescence locale : ils definissent un contrat de donnees partage entre contenu, services, serveur et frontend.

La source de verite fonctionnelle reside dans les schemas source consommes par le pipeline de generation, pas dans les fichiers TypeScript generes a partir de ces schemas.

- `schemas/interfaces/` : interfaces TypeScript generees depuis les YAML ; ne jamais modifier a la main
- `schemas/dtos/` : DTO TypeScript generes pour les frontieres techniques ; ne jamais modifier a la main
- `schemas/constants/` : constantes metier et jeux de valeurs statiques
- `schemas/enums/` : reserve aux enums TypeScript natifs si le projet en introduit
- `schemas/types/` : types metier non generes lorsque necessaire

## Rules

- les artefacts de `schemas/interfaces/` ne sont pas la source de verite fonctionnelle
- les artefacts de `schemas/dtos/` ne sont pas la source de verite fonctionnelle
- une modification structurelle doit etre faite dans les schemas sources, pas dans les fichiers generes
- les contrats exposes doivent rester coherents avec les usages applicatifs et serveur
