# Interface Generation

- Role: documenter la generation des interfaces TypeScript a partir des schemas YAML.
- Related: [./1.schema-source.md](./1.schema-source.md), [../../services/hooks/schema.ts](../../services/hooks/schema.ts)

## Overview

Les interfaces TypeScript sont generees par le hook Nuxt `build:before` via `runSchemaHook`.
Le mecanisme lit les schemas YAML et ecrit les artefacts dans `schemas/interfaces/`.
Le meme hook genere aussi les DTO dans `schemas/dtos/`.

## Main Flow

1. le hook `services/hooks/schema.ts` orchestre la generation
2. le chemin des schemas est resolu a partir de `SCHEMAS_PATH`
3. le generateur lit les YAML attendus
4. les types sont mappes en interfaces TypeScript
5. les fichiers sont ecrits dans `schemas/interfaces/`
6. les DTO sont ecrits dans `schemas/dtos/`

## Command

```bash
node scripts/run-schema-hook.mjs
```

## Prerequisite

- `SCHEMAS_PATH` doit pointer vers le dossier des schemas YAML
- le depot de schemas doit aussi contenir le dossier source des DTO attendu par le hook
- le dossier doit etre lisible et contenir les fichiers attendus

## Rules

- les artefacts generes doivent etre deterministes a contenu schema identique
- une erreur de lecture, de parsing ou d ecriture doit bloquer la generation
- toute modification du modele doit etre faite a la source, puis regeneree
