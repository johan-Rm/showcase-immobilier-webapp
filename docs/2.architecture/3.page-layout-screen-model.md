# Page, Layout, Screen Model

- Role: formaliser le modele de composition principal des routes du projet.
- Related: [../../app/pages/README.md](../../app/pages/README.md)

## Hierarchy

```text
PAGE
  -> LAYOUT
    -> SCREEN
      -> COMPONENT
        -> UI ELEMENT
```

## Definitions

### Page

Une page est un point d entree de route.
Elle assemble un ou plusieurs screens et orchestre l experience de la route.

### Layout

Le layout fournit le cadre persistant : header, footer, navigation, overlays et conteneur principal.

### Screen

Un screen est une unite d intention.
Il structure une section de l experience avec un objectif clair, une composition interne et un cycle de vie visuel.

### Component

Le composant implemente le rendu d un screen ou d un fragment de screen.
Il doit rester lisible, type et centre sur la presentation.

## Project Rule

Le projet privilegie une composition editoriale et lisible :

- page = orchestration de route
- layout = cadre structurel
- screen = unite d intention
- component = implementation d affichage
