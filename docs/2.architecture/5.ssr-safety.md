# SSR Safety

- Role: rappeler les invariants SSR de haut niveau du projet.

Le projet est SSR-safe par defaut.

Regles minimales :

- pas de code client-only sans garde explicite
- pas de dependance a `window`, `document` ou au DOM sans protection
- les balises critiques et le SEO doivent etre calculables cote serveur
- toute logique fragile a l hydratation doit etre isolee et documentee
