Mise en place d’un socle SEO complet par page, comprenant :

- métadonnées dynamiques (`title`, `description`)
- URL canonique par page
- gestion multilingue (`hreflang`, langue HTML, URLs localisées)
- balises sociales (Open Graph + Twitter Card)
- gestion des dates SEO (publication / mise à jour)
- données structurées (JSON-LD : page, organisation, navigation, liste de biens immobiliers + bien immobilier)
- sitemap XML + robots.txt
- contrôle de l’indexation (`meta robots`, règles globales, noindex hors prod)
- cohérence des réponses HTTP pour les moteurs
- contenu éditorial structuré (titres, texte, images)
- maillage interne entre les pages
- gestion optimisée des images
- éléments de base du rendu (favicon, viewport)
